# Subtitle sidecars

Six UTF-8 text files: English and Spanish in SRT, WebVTT and ASS.
All use the same two cues for the three-second Moon-orbit track examples.

See the [track guide](../TRACKS.md#separate-subtitle-files) for downloads,
timings and usage. Original caption text and styling are dedicated to CC0;
see [rights](../RIGHTS.md#added-audio-and-subtitles).
